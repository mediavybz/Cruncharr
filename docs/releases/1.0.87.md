**New**

- See verified edition labels, such as Uncensored, when a series offers more than one cut.
- See what each scheduler run added or skipped per show, and use **Download missing** to queue released episodes that have no file yet.
- Calendar cards and Add Download rows show the series name and episode number.

**Fixed**

- Sign in after Crunchyroll retired the previous TV client, and keep browsing as a guest while sign-in is failing.
- Download streams that previously failed at the start, and stop "Outdated Token" playback errors.
- Keep the existing file when a replacement download fails, and keep History when a series refresh fails.
- Recover damaged History, queue and configuration files instead of replacing them with empty defaults.
- Queue scheduled episodes once the selected dub is released, and resume release checks correctly after a restart.
- Match more episodes with Sonarr, including specials listed under longer titles, films listed as seasons, and recaps that shift numbering.
- Show episodes Sonarr already has as downloaded on the Calendar.
- Treat English dubs that also offer audio description as English, and tag separate audio-description tracks for media players.
- Load images, Browse, Calendar and History faster, and let downloads continue while other episodes transcode.
- Fix the Seasonal page, queue order, settings layout, theme colors and CLI commands.

**Security**

- Harden the API, file paths and container, and limit repeated sign-in attempts.

**Docker:** `ghcr.io/mediavybz/cruncharr:latest` or `ghcr.io/mediavybz/cruncharr:1.0.87` (AMD64 and ARM64). Update the container, then refresh the app page.
