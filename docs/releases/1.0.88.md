**New**

- Add newly released shows to the schedule automatically, in the audio and subtitle languages you choose.
- Search finds episodes by title, and Browse lists films.
- Set a RAM limit for downloads when the temp folder is a RAM disk. New downloads wait until they fit; 0 picks a limit automatically.
- With Sonarr, an episode waiting in the Cruncharr queue is unmonitored so Sonarr does not fetch a second copy. It is monitored again once the file is imported, or if the download fails or is removed.
- With Sonarr, a film that Crunchyroll lists on its own is matched to its special in the franchise's series.

**Fixed**

- Retry a download whose connection stops sending data, instead of waiting forever.
- Resume the download in progress after the app or container restarts, instead of cancelling it.
- Retry downloads when the Crunchyroll sign-in is briefly unavailable, instead of failing the whole queue.
- Use much less memory while idle, and make far fewer background requests to Sonarr.
- Hand each finished file to Sonarr on its own, so one file Sonarr cannot match no longer holds back the rest of the show.
- Show new releases sooner, stop signing in again on every refresh, and recover when Crunchyroll retires a sign-in client.
- Stop long series from freezing Calendar, History and Library.
- List every episode that shares a non-numeric label, and list each search result once instead of once per dub.
- Register and import film collections such as "X Movies" with Sonarr.
- Keep less in a RAM temp folder while episodes wait to transcode.

**Docker:** `ghcr.io/mediavybz/cruncharr:latest` or `ghcr.io/mediavybz/cruncharr:1.0.88` (AMD64 and ARM64). Update the container, then refresh the app page.
